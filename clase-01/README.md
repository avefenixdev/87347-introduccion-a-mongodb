# Clase 01 - Introducción a MongoDb

## Levantar el motor de base de datos

```sh
mongod
```

## Con el cliente MongoSh conectarnos

```sh
mongosh
```

# Cadena de conexión o string connection o uri

<mongodb://127.0.0.1:27017/>

# Conectarse al Servidor Mongo Atlas con MongoSH

```sh
mongosh "mongodb+srv://educacionit.aakwr9u.mongodb.net/" --apiVersion 1 --username mlpeducacion
```
